2. Segurança na Comunicação com o Banco (Prevenção de SQL Injection)

Última operação parametrizada executada:

SELECT * FROM cidadaos ORDER BY id DESC

Como os dados chegam com segurança: No Supabase (PostgREST) e no SQLite, os valores digitados pelo usuário nunca são concatenados na query SQL — são vinculados como parâmetros isolados (Prepared Statements $1, $2 ou ?), bloqueando 100% de ataques de SQL Injection.
